# Tramber website

- `index.html` — static, self-contained page (open directly in a browser or deploy as-is to any static host).
- `assets/clients/` — grey SVG client logos (carousel).
- `assets/certs/` — certification badges as SVG (CNCF in grey; Golden Kubestronaut, AWS, Azure in colour).
- `assets/illustrations/` — "connecting the dots" network illustration and the paper-grain texture.
- `design/` — source of the Claude Design canvas (`Main.dc.html`, `canvas.json`); asset URLs there point to the canvas's uploads.
- `tools/` — Python scripts used to trace logos/badges to SVG and to generate the network illustration.
